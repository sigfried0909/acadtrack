# AcadTrack
### Student Permit Monitoring and Academic Tracking System

**Saint Jude College – PHINMA Education**  
**College of Information Technology Education (CITE)**

## About the Project

AcadTrack is a web-based Student Permit Monitoring and Academic Tracking System developed for the College of Information Technology Education (CITE) of Saint Jude College – PHINMA Education.

The project aims to provide a more organized and accessible way of managing student permit records and academic information through a centralized digital platform.

It was designed to improve the organization of student records, simplify permit monitoring, and support academic administrative activities.

## Project Highlights

- **Student Management** – Supports the organization and management of student academic records.
- **Permit Monitoring** – Provides a digital platform for monitoring student permit records.
- **Academic Section Management** – Supports the management of academic sections and student assignments.
- **Faculty Management** – Facilitates faculty involvement in academic and permit-related activities.
- **Administrative Dashboard** – Provides an overview of relevant student and academic information.
- **Document Management** – Supports digital submission and monitoring of permit-related documents.
- **Record Exporting** – Provides document export capabilities for administrative reporting.
- **Account Management** – Includes user profile and account management features.

## User Roles

AcadTrack is designed around three primary user categories:

| Role | Description |
|---|---|
| Administrator | Handles system administration and academic record management. |
| Faculty | Supports academic and student permit monitoring activities. |
| Student | Accesses personal academic information and permit-related records. |

## Technology Stack

AcadTrack was developed using the following technologies:

- PHP
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- PDO

## Project Purpose

The development of AcadTrack focuses on improving how student permit records and academic information are organized and monitored.

By introducing a centralized digital platform, the project aims to minimize manual record management, improve accessibility of relevant information, and support a more structured academic administrative process.
